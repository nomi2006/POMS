## ✨ Key Features

This system is tailored for efficient manufacturing and inventory management, including:

- **🔐 Secure Authentication:** User login and registration system powered by Firebase Authentication.
- **📦 Inventory & Production Tracking:** 
  - **Yarn & Accessories Management:** Add, view, and manage purchase orders for raw materials.
  - **Process Tracking:** Record and monitor sent/received batches for Dyeing, Knitting, Embroidery, Packing, and Quality Control (QC).
  - **Reporting:** Dedicated reports for each stage of the manufacturing process (Yarn, Accessories, Dying, Knitting, QC, Embroidery, Packing).
- **👥 User Management:** Admin panel to add, view, and manage user roles manually.
- **📊 Interactive Dashboard:** Modern UI with charts and tables for quick data insights (ApexCharts).
- **📱 Fully Responsive:** Seamlessly adapts to desktop, tablet, and mobile screen sizes.
